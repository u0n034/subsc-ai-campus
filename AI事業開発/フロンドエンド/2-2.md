# 第2章:AIでLPのHTML構造を設計・生成する - ナレーション原稿

## セクション2:LP仕様をAIに伝わる形で言語化する(約30分/9,000字)

---

### イントロダクション:セクション2で学ぶこと

⭐️さて、セクション1では、HTMLの基本構造とセクション思考を学びました。

LPを「意味のある塊」に分けて捉える考え方を理解していただけたと思います。

では、セクション2では、いよいよ**AIにLP仕様を伝えるスキル**を身につけていきます。

⭐️ここで大事なのは、「AIに何をどう伝えるか」です。

AIは優秀ですが、魔法使いではありません。私たちの頭の中にあるイメージを、AIは直接読み取ることはできません。

だからこそ、**伝え方**が重要になってくるんです。

⭐️このセクション2では、3つのステップで学んでいきます。

**ステップ1**:まず、**悪いプロンプトの例**を見ます。どんな指示だと、AIが期待通りのHTMLを生成できないのか、実際に試してみます。

**ステップ2**:次に、**良いプロンプトの考え方**を学びます。LP構成を箇条書きで整理して、AIに明確に伝える方法をお見せします。

**ステップ3**:最後に、実際にCooklyのLP仕様書から情報を拾って、**プロンプト文を組み立てる様子**を実演します。

⭐️このセクションを終えたとき、みなさんは、自分のLPの仕様を、AIに伝わる形で言語化できるようになっています。

そして、セクション3では、実際にそのプロンプトを使って、HTMLを生成していきます。

では、始めていきましょう。

### 2-1 悪いプロンプト例を見てみる

⭐️まず、**やってはいけないプロンプトの例**を見てみましょう。

失敗から学ぶのが、一番早い方法です。

画面を共有しますね。ChatGPTの画面を開きます。

⭐️では、あえて、雑な指示を入力してみます。

こう入力してみましょう。

```
サービスのLPのHTMLを作って
```

これだけです。

Enterキーを押します。

⭐️AIが生成を始めました。待っていましょう。

はい、生成が完了しました。

どんなHTMLが出てきたか、見てみましょう。

スクロールしながら、ざっと見ていきますね。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8" />
  <title>AI業務自動化サポート｜サブスクで始めるDX</title>
  ...
</head>
<body>
  <header>
    <div class="logo">AI業務自動化サポート</div>
    <nav class="header-nav">
      <a href="#problem">こんなお悩み</a>
      <a href="#solution">選ばれる理由</a>
      ...
    </nav>
  </header>

  <section class="hero">
    <h1>ノーコードで「最初に効く1業務」から<br />AI業務自動化を始めませんか？</h1>
    ...
  </section>
  ...
</body>
</html>
```

⭐️さて、このHTML、一見、しっかりとした構造に見えますね。

`<header>`、`<section>`、`<footer>`という構造もあるし、CSSまで書かれています。

でも、**大きな問題がある**んです。

⭐️どこが問題か、見ていきましょう。

**問題1:完全に違うサービスのLPになっている**

私たちが作りたいのは、Cooklyという**オンライン料理教室**のLPです。

でも、AIが生成したのは、「AI業務自動化サポート」という**全く別のサービス**のLPになっています。

タイトルを見てください。「AI業務自動化サポート｜サブスクで始めるDX」。

ヒーローセクションのキャッチコピーも、「ノーコードで『最初に効く1業務』からAI業務自動化を始めませんか？」。

**料理教室とは全く関係ありません。**

⭐️**問題2:セクション構成が想定と全く違う**

私たちのワイヤーフレームでは、「ヒーロー」「Cooklyとは」「3つの理由」「受講生の声」「料金プラン」「FAQ」「最終CTA」という構成でした。

でも、生成されたHTMLは、「こんなお悩み」「選ばれる理由」「導入の流れ」「活用イメージ」という、BtoB向けのサービスLP特有の構成になっています。

**受講生の声もない。料理プランという概念もない。**

セクションの数も順番も、まったく違います。

⭐️**問題3:ターゲットが全く違う**

私たちのCooklyは、**忙しい会社員で料理を学びたい個人**がターゲットです。

でも、このLPは、「中小企業・小規模事業者向け」と明記されていて、**企業のバックオフィス担当者や経営者**がターゲットになっています。

ペルソナが完全にズレているんです。

⭐️**問題4:具体的な文言がまったく違う**

ワイヤーフレームに書かれていた「あなたのキッチンが、料理教室に変わる」というキャッチコピーは、どこにもありません。

3つの特徴も、「好きな時間に学べる」「プロの技術を基礎から」「質問し放題のサポート」ではなく、

「48時間で『最初に効く1業務』を特定」「ノーコード＆既存ツールを前提とした設計」「現場に定着するまで伴走」という、まったく別の内容になっています。

⭐️**問題5:料金体系も全く違う**

ワイヤーフレームでは、ベーシック¥2,980、スタンダード¥4,980、プレミアム¥9,800という**3つの個人向けプラン**でした。

でも、生成されたHTMLは、「月額99,000円〜」という**企業向けのサブスクリプション**になっています。

桁が一つも二つも違います。

⭐️どうでしょう。

AIは、確かにHTMLの構造は作ってくれました。それも、かなりしっかりとしたものを。

でも、**私たちが本当に欲しいLP**とは、まったく違うものができてしまいました。

⭐️これは、AIが悪いわけではありません。

私たちの**指示が曖昧だった**から、AIは「オンライン料理教室」という言葉から連想できる範囲で、一般的なBtoB SaaSのLPの構造を参考にして、こういう結果を出してしまったんです。

「オンライン料理教室のLPのHTMLを作って」という指示だけでは、

- どんなサービス名で
- どんなセクション構成にしたいのか
- どんな文言を入れたいのか
- どんな要素が必要なのか
- ターゲットは個人なのか企業なのか
- 料金体系はどうなっているのか

こういった情報が、まったく伝わっていないんです。

AIは、与えられた情報が少ないと、**自分の学習データの中から「それっぽいもの」を組み合わせて**答えを出そうとします。

結果、私たちの意図とは全く違うものができてしまうんです。

⭐️だからこそ、**良いプロンプトを書く必要がある**んです。

次のステップで、良いプロンプトの考え方を見ていきましょう。

---

### 2-2 良いプロンプトの考え方(構成を箇条書きで伝える)

⭐️では、どうすれば、AIに的確にLP仕様を伝えられるのでしょうか。

答えは、**構成を箇条書きで整理して伝える**ことです。

⭐️良いプロンプトには、共通するパターンがあります。

それを、今からお見せしますね。

⭐️ここに、「良いプロンプトのテンプレート」があります。

```
＜目的＞
◯◯というサービスのランディングページを作りたい。
ターゲットは△△で、ゴールは□□です。

＜全体構成＞
以下のセクション構成でHTMLを生成してください。

1. ヘッダー:
   - 左側にロゴ
   - 右側に「無料相談」ボタン

2. ヒーロー(ファーストビュー):
   - 左側に大きなキャッチコピー「◯◯◯◯」
   - その下に説明文「△△△△」
   - CTAボタン「□□□□」
   - 右側にメイン画像

3. サービス説明:
   - セクションタイトル「◯◯とは」
   - 説明文を2〜3段落

4. 3つの特徴:
   - セクションタイトル「◯◯の3つの特徴」
   - 特徴1:タイトル「◯◯」、説明文「△△」
   - 特徴2:タイトル「◯◯」、説明文「△△」
   - 特徴3:タイトル「◯◯」、説明文「△△」

(以下、同様に続く)
```

⭐️このテンプレートのポイントを、解説していきます。

**ポイント1:目的を明確にする**

まず、冒頭で「何のためのLPか」を伝えます。

「Cooklyというオンライン料理教室のランディングページを作りたい」

こう伝えることで、AIは「ああ、料理教室のLPなんだな」と理解します。そうすると、生成される文言も、料理教室に合ったものになりやすくなります。

さらに、「ターゲットは忙しい会社員で、ゴールは無料体験レッスンの予約です」と伝えると、AIは、ターゲットに刺さる文言や、CTAボタンの文言を考えやすくなります。

⭐️**ポイント2:セクション構成を番号付きで列挙する**

「1. ヘッダー」「2. ヒーロー」「3. サービス説明」…という具合に、セクションを順番に列挙します。

これが、さっき学んだ「セクション思考」を、プロンプトに反映させる方法です。

AIは、この番号順にHTMLを生成してくれます。だから、構成が明確になります。

⭐️**ポイント3:各セクションの中身を具体的に書く**

ただ「ヒーロー」と書くだけでは不十分です。

- 左側に大きなキャッチコピー
- その下に説明文
- CTAボタン
- 右側にメイン画像

という具合に、**セクションの中に何が必要か**を箇条書きで列挙します。

さらに、キャッチコピーの文言が決まっているなら、それも書きます。

「大きなキャッチコピー『あなたのキッチンが、料理教室に変わる』」

こう書けば、AIはその文言をそのまま使ってHTMLを生成してくれます。

⭐️**ポイント4:文言が決まっていない部分は、ダミーテキストでOK**

もちろん、すべての文言が最初から決まっているわけではありません。

たとえば、サービス説明の文章が、まだ完成していないこともあるでしょう。

そういうときは、「説明文を2〜3段落」とだけ書いておけば大丈夫です。

AIは、ダミーの文章を入れてくれます。後から、私たちが正しい文章に差し替えればいいんです。

⭐️**ポイント5:画像はダミーで指示する**

LPには、たくさんの画像が必要です。でも、HTML生成の段階では、まだ画像ファイルが用意できていないことも多いですよね。

そういうときは、「右側にメイン画像(プレースホルダー)」という具合に、**画像の位置だけ指示**しておきます。

AIは、`<img src="hero-cooking.jpg" alt="料理シーン">`のような形で、プレースホルダー(仮の画像パス)を入れてくれます。

後から、実際の画像ファイルと差し替えればOKです。

⭐️どうでしょう。

こうして、**セクションごとに、必要な要素を箇条書きで整理する**だけで、AIへの指示が格段に明確になります。

これが、良いプロンプトの基本パターンです。

⭐️では、次のステップで、実際にCooklyのLP仕様書から情報を拾って、このようなプロンプトを組み立てる様子をお見せします。

---

### 2-3 プロンプト文を整える実演

⭐️では、実際に、Cooklyの仕様書を見ながら、AIに渡すプロンプトを組み立てていきましょう。

ここに、CooklyのLP仕様書があります。

⭐️今から、この仕様書の情報を、一つずつ拾っていって、プロンプトの箇条書きに変換していきます。

右側に、プロンプトを書いていきますね。

⭐️まず、冒頭に**目的**を書きます。

```
＜目的＞
Cooklyというオンライン料理教室のランディングページを作りたい。
ターゲットは、料理を学びたいけれど料理教室に通う時間がない忙しい会社員。
ゴールは、無料体験レッスンの予約を獲得すること。
```

仕様書の「サービス概要」と「ターゲット・ペルソナ」のセクションから、この情報を拾いました。

⭐️次に、**全体構成**を書いていきます。

```
＜全体構成＞
以下のセクション構成で、セマンティックなHTMLを生成してください。
```

まず、こう書いておきます。

「セマンティックなHTML」という言葉を入れることで、AIに「`<div>`ばかりではなく、意味のあるタグを使ってね」と伝えています。

⭐️では、セクションを一つずつ書いていきましょう。

**セクション1:ヘッダー**

仕様書のセクション1を見ます。

左側に「Cookly」というロゴがあって、中央に「Cooklyについて」「料金プラン」「お問い合わせ」というナビゲーションメニュー、そして右側に「無料体験はこちら」というボタンがありますね。

これをそのまま箇条書きにします。

```
1. ヘッダー:
   - 左側にロゴ(テキストで「Cookly」)
   - 中央にナビゲーションメニュー(「Cooklyについて」「料金プラン」「お問い合わせ」)
   - 右側に「無料体験はこちら」ボタン
```

ロゴ画像がまだないので、「テキストで」と指定しました。後から画像に差し替えることもできます。

⭐️**セクション2:ヒーロー(ファーストビュー)**

仕様書のセクション2を見ます。

左側に大きく「あなたのキッチンが、料理教室に変わる」というメインキャッチコピー(h1)があります。

その下に、サブコピー「一流シェフから学ぶ、本格オンライン料理レッスン」が1行続いています。

そして、オレンジの「無料体験レッスンを予約する」ボタン。

右側には、料理シーンの画像が配置されています。

これを箇条書きにしていきます。

```
2. ヒーロー(ファーストビュー):
   - 左側のコンテンツ:
     * メインキャッチコピー(h1):「あなたのキッチンが、料理教室に変わる」
     * サブコピー(1行):「一流シェフから学ぶ、本格オンライン料理レッスン」
     * CTAボタン:「無料体験レッスンを予約する」
   - 右側に料理シーンの画像(プレースホルダー、hero-cooking.jpg)
```

キャッチコピーには、「h1」というタグの指定も入れました。セクション1で学んだように、ページ全体のメインタイトルは`<h1>`タグにするんでしたね。

⭐️**セクション3:Cooklyとは(サービス説明)**

仕様書のセクション3を見ます。

「Cooklyとは」というセクションタイトル(h2)があって、その下に説明文が3段落あります。

仕様書には、この3段落の文章が全部書かれていますね。これをそのまま引用しましょう。

```
3. Cooklyとは(サービス説明):
   - セクションタイトル(h2):「Cooklyとは」
   - 説明文(3段落):
     「Cooklyは、一流レストランで活躍するプロのシェフから、自宅にいながら本格的な料理技術を学べるオンライン料理教室です。24時間いつでも視聴可能な動画レッスンと、リアルタイムで質問できるライブレッスンで、あなたの料理スキルを確実に向上させます。
     
     包丁の持ち方から始まる基礎レッスン、本格的なフレンチやイタリアンの技法、家庭で作れるプロの味まで。あなたのペースで、あなたのレベルに合わせて学べる環境を提供します。
     
     わからないことがあれば、チャットでいつでも質問できます。レシピも見放題。料理を楽しみながら、確実にスキルアップできる場所、それがCooklyです。」
```

こう書けば、AIは仕様書通りの文章を使ってHTMLを生成してくれます。

⭐️**セクション4:Cooklyが選ばれる3つの理由**

仕様書のセクション4を見ます。

3つのカードが横に並んでいますね。

それぞれに黄色いアイコンがあって、タイトルと説明文が書かれています。

左から「好きな時間に学べる」「プロの技術を基礎から」「質問し放題のサポート」という3つの理由です。

仕様書には、それぞれの説明文も書かれているので、そのまま引用します。

```
4. Cooklyが選ばれる3つの理由:
   - セクションタイトル(h2):「Cooklyが選ばれる3つの理由」
   - 理由を3つ、横並びのカードで表示
   - 理由1:
     * アイコン画像:時計のアイコン(黄色い円形背景、icon-clock.svg)
     * タイトル(h3):「好きな時間に学べる」
     * 説明:「動画レッスンは24時間視聴可能。ライブレッスンも録画が残るので、見逃しても安心。あなたのペースで学習できます。」
   - 理由2:
     * アイコン画像:シェフ帽のアイコン(黄色い円形背景、icon-chef.svg)
     * タイトル(h3):「プロの技術を基礎から」
     * 説明:「一流レストランで働くシェフが講師。包丁の持ち方から本格レシピまで、丁寧に指導します。」
   - 理由3:
     * アイコン画像:吹き出しのアイコン(黄色い円形背景、icon-support.svg)
     * タイトル(h3):「質問し放題のサポート」
     * 説明:「わからないことがあれば、チャットでいつでも質問できます。レシピも見放題で、安心して学べます。」
```

ここでは、見出しレベルも指定しました。セクションタイトルは`<h2>`、各理由のタイトルは`<h3>`です。

⭐️**セクション5:受講生の声**

仕様書のセクション5を見ます。

「受講生の声」というセクションタイトルの下に、3つのカードが横に並んでいます。

各カードには、丸い顔写真、名前、年齢、職業、そしてコメントが記載されています。

仕様書には、3人の受講生の実名とコメントが書かれていますね。これをそのまま使いましょう。

```
5. 受講生の声:
   - セクションタイトル(h2):「受講生の声」
   - 受講生を3名分、カード形式で横並び表示
   - 受講生1:
     * 顔写真(丸型、プレースホルダー、student-1.jpg)
     * 名前:田中 美咲さん
     * 年齢・職業:35歳・会社員
     * コメント:「仕事と育児で忙しい中、自分のペースで学べるのが最高です。子どもが寝た後の夜時間を使って、少しずつスキルアップできています。」
   - 受講生2:
     * 顔写真(丸型、プレースホルダー、student-2.jpg)
     * 名前:佐藤 健太さん
     * 年齢・職業:28歳・会社員
     * コメント:「料理は全くの初心者でしたが、基礎から丁寧に教えてもらえて、今では友人を招いてホームパーティーを開けるまでになりました。」
   - 受講生3:
     * 顔写真(丸型、プレースホルダー、student-3.jpg)
     * 名前:鈴木 優子さん
     * 年齢・職業:42歳・主婦
     * コメント:「料理のレパートリーが大幅に増えました。家族からも『レストランみたい!』と言われるようになり、料理が楽しくなりました。」
```

このように、仕様書に具体的な内容が書かれている場合は、それをそのままプロンプトに書き写すことで、AIは正確にHTMLを生成してくれます。

⭐️**セクション6:料金プラン**

仕様書のセクション6を見ます。

「料金プラン」というセクションタイトルの下に、3つのプランカードが横に並んでいます。

左から、「ベーシック ¥2,980」「スタンダード ¥4,980」「プレミアム ¥9,800」です。

真ん中のスタンダードプランが、「人気No.1」として強調されていますね。

各プランの特徴も、仕様書に詳しく書かれているので、それをそのまま引用します。

```
6. 料金プラン:
   - セクションタイトル(h2):「料金プラン」
   - プランを3つ、横並びのカードで表示。中央のスタンダードプランを強調。
```
