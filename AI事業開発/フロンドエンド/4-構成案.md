## セクション1：JavaScriptの役割とファイル構成を理解する（約20分）

**形式：スライド＋エディタ＆ブラウザの画面共有**

### 1-1 JavaScriptは「動き・仕掛け担当」

* スライドで再度3つの役割を整理：

  * HTML：なにがあるか（構造・中身）
  * CSS：どう見えるか（色・余白・配置）
  * JavaScript：どう動くか（挙動・インタラクション）
* サンプルLP画面を見ながら：

  * FAQがクリックで開閉する
  * CTAボタンを押すとページ下部のフォームにスクロールする
    など、これから実装する「動き」の例を先に見せる

### 1-2 JavaScriptファイルと読み込みの確認

* `index.html` を表示して：

  * `<script src="script.js"></script>` がどこに書かれているかを確認
  * 「基本的には `</body>` タグの直前に置きます」というベストプラクティスを紹介
* `script.js` ファイルを開き、最初は空か、簡単なコメントだけの状態を見せる

### 1-3 「イベント」という考え方

* ごくシンプルな例で実演：

  * HTML側で仮のボタンを用意しておく（例：`<button id="testButton">テスト</button>`）
  * `script.js` に以下のようなコードを書いて保存：

    ```js
    const button = document.getElementById('testButton');
    button.addEventListener('click', () => {
      alert('ボタンがクリックされました');
    });
    ```
  * 実際にボタンをクリック → アラートが出る様子を見せる
* ナレーション：

  > JavaScriptは「○○されたら△△する」という“ルール”を書いていく言語です。
  > 今の例だと「ボタンがクリックされたら、アラートを出す」という動きですね。

## セクション2：ページ内スクロールとヘッダー周りのインタラクション（約35分）

**形式：AIでコード生成 → script.jsに貼り付け → ブラウザ確認**

### 2-1 CTAボタンからフォームセクションへのスムーズスクロール

* LPのHTMLから、CTAボタンとフォームセクションのIDを確認（エディタ上でハイライト）

  * 例：`<a href="#contact" class="btn btn-primary">無料相談はこちら</a>`
    `<section id="contact">…</section>`
* ChatGPTに以下のようなプロンプトを打つ様子を見せる：

  ```text
  次のHTMLのCTAボタンをクリックしたときに、
  ページ内の #contact セクションまでスムーズスクロールする
  JavaScriptを書いてください。

  条件：
  - script.js に記述する前提
  - 短くシンプルなコード
  - 初心者にも分かるよう、日本語コメントを入れてください。
  ```
* 生成されたコードを `script.js` に貼り付けて保存 → 実際にCTAボタンをクリック →
  ページがするっとスクロールする様子を見せる
* コメントを読み上げながら、「どこでボタンを取得して、どこでscrollしているか」をざっくり解説

### 2-2 固定ヘッダーのナビゲーション（任意要素）

* ヘッダーにナビゲーションリンク（例：サービス紹介／料金／FAQ）を想定
* スクロール位置に応じて、今どこのセクションを見ているかをナビでハイライトする簡易例を、AIに依頼：

  ```text
  スクロール位置に応じて、現在表示されているセクションに対応する
  ナビゲーションリンクに .is-active クラスを付けるシンプルなJavaScriptを書いてください。
  ```
* 生成コードを貼り、動作確認：

  * スクロールしながら、ナビゲーションの色がセクションに応じて変わる様子を見せる
* 「こういった動きもJavaScript側のルールで制御している」と説明しつつ、
  詳細なロジックまでは追いかけなくて良いと強調

## セクション3：FAQのアコーディオンとフォームの基本実装（約35分）

**形式：AIコード生成＋実装デモ**

### 3-1 FAQアコーディオンの実装

* FAQセクションのHTMLを確認（質問と答えのブロック）：

  ```html
  <div class="faq-item">
    <button class="faq-question">Q. ○○○？</button>
    <div class="faq-answer">A. △△△……</div>
  </div>
  ```
* ChatGPTに次のようなプロンプトでコードを依頼：

  ```text
  以下のFAQセクションのHTMLに対して、
  質問(faq-question)をクリックしたら答え(faq-answer)が開閉する
  アコーディオンのJavaScriptを書いてください。

  条件：
  - script.js に記述
  - 最初は答えを非表示にする
  - 開いている質問をもう一度押すと閉じる
  - 複数の質問が同時に開いていてもOK
  - 日本語コメントをお願いします。
  ```
* 生成されたコードを `script.js` に追記し、CSS側で `.faq-answer { display: none; }` なども設定
  → クリックで開閉する様子をブラウザで確認
* コードのポイントをコメントに沿って解説：

  * `document.querySelectorAll` で複数要素を取得している
  * `forEach` で1つずつイベントを付与している

### 3-2 フォーム（フロント側）のHTML確認と微調整

* `contact` セクションのHTMLを確認し、以下のような構成になっていることを説明：

  * 名前（必須）
  * メールアドレス（必須）
  * お問い合わせ内容（任意 or 必須）
  * 送信ボタン
* 足りない場合は、ChatGPTにHTML自体も生成させるデモを軽く行う：

  ```text
  contact セクション用に、名前・メール・お問い合わせ内容を入力できる
  シンプルなフォームHTMLを書いてください。
  各項目には label を付け、必須項目には * を付けてください。
  action や method は指定しなくて構いません。
  ```

### 3-3 フロント側の入力チェック（バリデーション）

* ChatGPTに対して次のようなコードを依頼：

  ```text
  contact フォームについて、
  以下のルールで入力チェックするJavaScriptを書いてください。

  - 名前とメールアドレスは必須
  - メールアドレスがメール形式でない場合はエラー
  - エラー時は、該当する入力欄の下に赤文字でメッセージを表示
  - 正しく入力されていれば、フォーム下部に「送信が完了しました（ダミー）」と表示し、
    フォームの中身をリセットする

  script.js に追記することを想定し、日本語コメントも付けてください。
  ```
* 生成されたコードを `script.js` に追加し、実際に：

  * 入力ミス → エラーメッセージ表示
  * 正しく入力 → 完了メッセージ表示
    の様子をブラウザで実演
* ナレーション：

  > 実際の送信処理（サーバーにデータを送る）はバックエンドの領域なので、
  > この講座では「フロント側でのチェックと完了メッセージ」までをゴールにしています。

## セクション4：エラー・トラブルをAIと一緒に解決する流れ（約20分）

**形式：あえてエラーを起こして → AIに相談 → 修正するデモ**

### 4-1 よくあるエラーの例をわざと作る

* 例1：HTML側のIDと、JavaScriptで参照しているIDが違う
  → `document.getElementById('contactForm')` なのに、HTMLは `id="contact-form"` になっている など
* `script.js` 実行時にブラウザの開発者ツール（コンソール）を開き、
  エラーメッセージ（`Cannot read properties of null` etc.）が出ている様子を見せる

### 4-2 エラー内容をAIに投げるデモ

* コンソールのエラーメッセージをコピーし、ChatGPTに貼り付けて質問：

  ```text
  次のエラーが出ています。原因と、初心者にも分かるような修正方法を教えてください。

  （エラーメッセージ）
  Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')
  at script.js:10
  ```
* AIからの回答を表示しながら、

  * 「IDが一致していない可能性」などの原因説明
  * 「HTMLのidを〜に変えるか、JavaScriptの方を〜に変えてください」といった提案
    を確認

### 4-3 AIの指示通りに修正 → 正常に動くまでの流れを通しで見せる

* 実際にHTMLやJSの該当箇所を書き換え → 保存 → 再読み込み
  → エラーが消え、動作が戻る様子を見せる
* ナレーション：

  > すべてを自力でデバッグできる必要はありません。
  > 「どんなエラーが出ているか」「何をしたいのか」をAIに共有し、
  > 一緒に原因を探してもらう、というスタンスでOKです。
