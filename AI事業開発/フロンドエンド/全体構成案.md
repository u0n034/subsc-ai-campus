## 全体像・ゴール

**ゴール**

* HTML/CSS/最低限のJavaScriptの「構造」を理解し、AIにコードを書かせて自分で怖がらずに修正できるようになる
* Figmaなど本格デザインツールなしでも、AI＋簡易デザインルールでそれっぽいフロント実装ができる
* Git やローカル開発環境がわからなくても、CodeSandbox/StackblitzなどのブラウザIDEとAIだけでLPを公開できる

---

## 構成案（8時間）

### 第1章：AI時代のフロントエンド開発の全体像（1時間）

**狙い：** 「コード＝難しい」という抵抗感を外しつつ、AIを前提としたフロントエンド開発フローを理解させる。

#### セクション1 フロントエンド開発とは何か

* HTML / CSS / JavaScript がそれぞれ担当している役割
* デザイナー / エンジニア / AIディレクターの境界線

#### セクション2 「AI＋ブラウザIDE」で完結する開発フロー

* CodeSandbox / Stackblitz / Replit などの「ブラウザで動く開発環境」の紹介
* ChatGPT / Cursor などのAIと連携したコーディングのイメージ

#### セクション3 既存講座とのつながり

* 企画＆コピー＆画像＆STUDIO実装 → 「今度はコードで同じLPを再現してみる」ロードマップを提示

#### セクション4 この講座で作るもの

* 1本のLPを題材に、「AIが生成したHTML/CSS/JS」を読み解きながら完成させるゴールの提示

**成果物イメージ：**

* 講座全体のロードマップ図
* サンプルLPの完成イメージ（スクリーンショット）

---

### 第2章：AIでHTML構造を設計・生成する（2時間）

**狙い：** HTMLを「タグの意味の集合」として理解し、AIに構造を作らせるスキルを身につける。

#### セクション1 HTMLの超基本をAIでざっくり理解

* `<header>` / `<main>` / `<section>` / `<footer>` などの構造タグ
* テキスト・画像・ボタンなど、LPでよく使う要素だけに絞って解説
* 「表現したいパーツ → どのタグを使うか」をAIに相談する練習

#### セクション2 ワイヤーフレーム → HTML への変換をAIに任せる

* 既存講座で作ったLP構成案（ワイヤー）を前提に、
  ChatGPT に「この構成をセマンティックなHTMLに変換して」と依頼
* セクションごとにHTMLを分割生成させるプロンプト設計

#### セクション3 AIが書いたHTMLを読んでコメントをつける

* 「ここは何をするコード？」とAIに1行ずつ日本語で説明させる
* `<div>` だらけのコードを、タグを置き換えてセマンティックに直させるワーク

#### セクション4 ちょっとした修正を自分でやってみる

* 見出しレベルの調整（`<h1>` / `<h2>`）
* CTAボタンの文言を変える
* セクションの順番を入れ替える

**成果物：**

* 自分のLPの「HTMLのみ完成版」（まだスタイルなし）

---

### 第3章：AIでCSSレイアウト＆デザインの骨格を作る（2時間）

**狙い：** 細かいデザイン理論ではなく「実務でよく使うパターン」に絞って、AIにCSSを書かせて調整できるようにする。

#### セクション1 CSSの最低限の考え方

* 「どの要素に」「どんな見た目を当てるか」の仕組み（セレクタ、クラス）
* まずは「余白・色・フォント・レイアウト」の4つだけ抑える

#### セクション2 レイアウトの王道パターンをAIに生成させる

* ヒーローセクション（左テキスト＋右画像）
* 3カラムの特徴紹介
* お客様の声カードレイアウト
* フッター（ロゴ＋リンク）
* Flexbox / Grid を使ったレイアウトパターンをAIに書かせる

#### セクション3 モバイルファーストのレスポンシブ対応

* 「スマホだと縦1列、PCだと横3列」の指定をAIにやってもらう
* `@media` クエリの意味だけ理解し、実装はAIに依頼

#### セクション4 デザイン一貫性のルールをAIに作らせる

* カラーパレット、フォントサイズ、余白の基準（8px単位など）を文章で決める
* そのルールに沿ったCSSの共通クラスをAIに生成させる

#### セクション5 デザイン崩れをAIと一緒にデバッグ

* 「なぜか画像がはみ出る」「スマホで崩れる」時に、
  スクショ＋HTML/CSSを投げて、原因と修正案をAIに出させる

**成果物：**

* 自分のLPの「レスポンシブ対応済みHTML＋CSS」
  （PC/スマホで一応見栄えが整った状態）

---

### 第4章：AIでインタラクションとフォームを実装する（1.5時間）

**狙い：** 「動きのあるLP」をAIに実装させる経験を通じて、JavaScriptに対する心理的ハードルを下げる。

#### セクション1 JavaScriptは何をしているのか

* 「クリックされたら◯◯する」「スクロールしたら◯◯する」だけ理解
* DOM（ドム）という言葉だけ押さえる（詳しい内部はAI任せ）

#### セクション2 よくあるインタラクションをAIに実装してもらう

* ページ内スクロール（CTAボタン → フォームセクションへ）
* FAQアコーディオン（質問をクリックすると回答が開く）
* スクロール時のふわっとアニメーション（必要なら簡易なもの）

#### セクション3 お問い合わせフォームの実装（フロント側）

* HTMLフォーム（名前・メール・問い合わせ内容）
* 必須チェック・簡単な入力チェック
* バリデーションエラー時の表示パターン（赤枠・メッセージ）
* バックエンドは別講座想定なので、送信は「ダミーアラート」まででもOK

#### セクション4 エラーが出たときのAIへの聞き方

* コンソールエラーをスクショ or コピーしてAIに相談
* 「このエラーの原因と、初心者にもできる直し方を教えて」と聞くテンプレ

**成果物：**

* インタラクション付きのLP（FAQ開閉・フォーム入力チェックなど）

---

### 第5章：公開・改善と「AIディレクターとしてのフロントスキル」整理（1.5時間）

**狙い：** 作って終わりではなく、「公開→改善→保守」をAIと回せる状態に持っていく。

#### セクション1 LPを公開してみる

* GitHub Pages / Netlify / Vercel のどれか1つに絞ったデプロイ手順
* ZIPアップロード or Git なしでも完結するルートを紹介

#### セクション2 修正依頼に応えるシミュレーション

* 「CTAボタンをもう少し目立たせて」「料金表を1つ追加して」などの要望に対し、
  HTML/CSS/JSのどこを触るべきかをAIに聞きながら修正

#### セクション3 「AIディレクター」としてのフロントエンド指示テンプレ集

* 「ワイヤーフレーム→HTML」「デザインルール→CSS」「挙動→JS」それぞれのプロンプト例
* デザイナー/エンジニアに渡せる仕様書テンプレ（JSONや表形式ではなく、日本語文章＋スクショ中心）

#### セクション4 学習の次のステップ

* React / Tailwind / Next.js などへの橋渡し
* 「どこまでをAIに任せ、どこからをエンジニアに任せるか」の線引き

**成果物：**

* インターネット上に公開された自作LP
* 「AIフロントエンドディレクター」としてのチェックリスト＆プロンプト集
