## 第3章：AIでCSSレイアウト＆デザインの骨格を作る（120分）

※すべて講師が実演。受講者は視聴しながら、必要に応じて動画を一時停止して追従する形式。

### ゴール（章の冒頭で明示）

* CSSの「役割」と基本的な書き方を、雰囲気ではなく**画面とコードの対応で理解**できる
* 色・フォント・余白など、LPに必須な見た目の要素を**AIにCSSを書かせて整える流れ**が分かる
* ヒーロー・3カラム・カード型など、よくあるレイアウトパターンをCSSで作る手順を理解できる
* スマホ／PC 両対応の**レスポンシブデザインの基本プロセス**をイメージできる

### セクション1：CSSの基本とファイル構成を理解する（約20分）

**形式：スライド＋エディタ＆ブラウザの画面共有**

**1-1 CSSは「見た目担当」であることを再確認**

* スライドでHTMLとCSSの関係を図解：

  * HTML：ページの骨組み・内容
  * CSS：色・フォント・余白・配置などの見た目
* 第2章で作成した `index.html` を再表示し、
  「今はほぼブラウザのデフォルトスタイルだけで表示されている状態」と説明

**1-2 CSSファイルの位置と読み込み方法**

* `index.html` を画面共有しながら：

  * `<head>` 内に `<link rel="stylesheet" href="style.css">` があることを確認
  * `style.css` ファイルをエディタで開き、最初は空に近い状態であることを見せる
* もしインラインスタイルや `<style>` タグを使う場合があれば、簡単に違いを説明しつつ、
  「この講座では基本的に `style.css` にまとめます」と方針を伝える

**1-3 セレクタとプロパティの超基本**

* 簡単な例を実演：

  * `body { background-color: #f5f5f5; }` を書いて保存 → 画面の背景色が変わる
  * `.cta-button { background-color: #…; color: #fff; }` などクラス指定を見せる
* ナレーションで：

  > CSSは「どの要素に」「どんな見た目を当てるか」を書く言語です。
  > 左側が“誰に？”、右側の `{…}` の中が“どんな見た目？”です。

### セクション2：ブランドに合わせた「ベーススタイル」をAIで作る（約30分）

**形式：スライド＋AI画面＋エディタ実演**

**2-1 ブランドルールを文章で定義する**

* LPの想定ブランドイメージ（ターゲット・トーン）を再確認するスライド：

  * 例）「30代のフリーランス向け、落ち着いた信頼感のあるオンラインコーチング」など
* 講師が、ChatGPT に渡す文章をまとめていく様子を画面で見せる：

  * メインカラー／アクセントカラー
  * フォントサイズの基準（タイトル・見出し・本文）
  * 行間・余白の雰囲気（ゆったり／きっちり など）

**2-2 AIに「ベースCSS」を書かせるデモ**

* ChatGPTに以下のような依頼を実演：

  ```text
  次のブランドイメージに合う、LP用のベースCSSを作ってください。

  ＜条件＞
  - ファイル名は style.css を想定
  - body、見出し（h1〜h3）、p、a、ボタン（.btn など）に対して
    基本的な色・フォントサイズ・行間・余白を定義してください。
  - 全体の雰囲気は「落ち着いた信頼感」「PC・スマホ両方で見やすい」を重視。
  ```
* 生成されたCSSを `style.css` に貼り付けて保存 → 画面の変化を確認

  * タイトルのサイズ
  * 本文の行間
  * 全体の余白感
    を「前後比較」して見せる

**2-3 不要なCSS・分かりにくい部分をAIにリライトさせる**

* 生成CSSの中から、少し冗長な記述や使っていないクラスを見つけて、

  * 「このCSSを、初心者でも読みやすいようにコメント付きで整理してください」
    とAIに依頼するデモ
* コメント付きCSSを貼り直し、コメントの読み方を解説：

  * `/* ページ全体の基本設定 */`
  * `/* 主要なボタンスタイル */` など

### セクション3：ヒーロー・3カラム・カードレイアウトをAIで組み立てる（約35分）

**形式：AIでCSS生成 → エディタに反映 → ブラウザ確認のデモ**

**3-1 ヒーローセクションの2カラムレイアウト**

* 第2章で作ったヒーローセクションのHTMLをエディタで表示
* ChatGPTに以下のようなプロンプトでCSSを依頼：

  ```text
  次のヒーローセクションのHTMLに対応するCSSを書いてください。
  PCでは左にテキスト、右に画像が横並びになる2カラムレイアウトにし、
  スマホでは縦1列になるようにしてください。
  Flexboxを使ってください。
  ```
* 生成されたCSSを `style.css` に追加し、
  プレビューで「PC時：横並び」「幅を狭めた時：縦並び」になる様子を見せる
* 行単位でCSSを指し示しながら、ざっくり意味を解説：

  * `display: flex;`
  * `justify-content`, `align-items`
  * `flex-basis` や `width` の使い方

**3-2 メリットセクションの3カラムカードレイアウト**

* メリットセクションのHTML（3つの特徴カード）を表示
* ChatGPTにプロンプト例：

  ```text
  このメリットセクションのHTMLを、PCでは3カラム、
  タブレット・スマホでは2カラムまたは1カラムになるようなレスポンシブレイアウトにしたいです。
  CSS Grid または Flexboxを使ったシンプルなCSSを書いてください。
  ```
* 生成CSSを反映し、画面幅を変えながら
  「3 → 2 → 1カラムに切り替わる」様子を見せる
* 「どのブレークポイントで切り替えているか」を解説しつつ、
  `@media (min-width: ...)` の部分に注目してもらう

**3-3 お客様の声・実績のカードデザイン**

* お客様の声セクションのHTMLをベースに、

  * 吹き出し風／カード風スタイルをAIに依頼
* プロンプト例：

  ```text
  お客様の声のセクションをカードデザインにしたいです。
  それぞれの声を、角丸・影付きのカードとして表示し、
  カード同士の間に適度な余白を入れてください。
  ```
* 生成CSSを反映し、カードの見た目が変わる様子を確認
* 併せて、「影を弱めたい」「もう少しフラットにしたい」などの
  微調整リクエストをAIにするデモも実施

### セクション4：レスポンシブデザインの考え方とAI活用（約25分）

**形式：ブラウザのウィンドウ幅を動かしながらのデモ＋スライド**

**4-1 モバイルファーストという考え方**

* スライドで、モバイルファーストの概念をシンプルに説明：

  * 「スマホで見やすい状態を先に作る」
  * 「そこから画面が広がるときに追加でレイアウトを変える」
* 第3章で書いたCSSが「どちらの方向」で書かれているかを確認しつつ、
  モバイル側がちゃんと読めるかをスマホ幅でチェックするデモ

**4-2 1つのセクションに注目して @media を読み解く**

* 例としてメリットセクションを取り出し、
  CSSの `@media` 部分だけを拡大表示
* ナレーションで：

  > 「画面の幅が○○px以上になったら、
  > このレイアウトに切り替えます」という「条件文」になっています。
* 条件の数字（例：768px／1024px）が何を意味するかを、
  タブレット・PCのざっくりした目安と絡めて説明

**4-3 AIにレスポンシブ調整を依頼するパターン**

* わざと「スマホで少し読みにくいCSS」例を用意し、

  * 文字が小さい
  * 余白が詰まりすぎ
* それをブラウザで表示 → 問題点を画面上で指摘した上で、
  ChatGPTに以下のように依頼するデモ：

  ```text
  スマホ幅（画面幅が480px以下）のとき、
  本文のフォントサイズを少し大きくし、
  セクション上下の余白を広げたいです。
  その調整用のCSSだけ追記してください。
  ```
* 生成された追記用CSSを `style.css` の下部に追加 → 改善前後を比較
