

# ①「ワークフロー自動化とAPI連携」8時間（n8n使用）

## コースコンセプト

* **対象**：非エンジニア〜ライトエンジニア
* **ゴール**

  * 自分の業務を「フロー図」に分解して考えられる
  * n8n で「トリガー → 処理 → 通知」の基本フローを組める
  * APIキー／REST APIの超基礎を理解し、**HTTP Requestノードで外部サービスと連携できる**
  * 「自社で試してみたい自動化アイデア」を1〜2本、具体的なワークフロー案に落とし込む

## 第1回：n8nとワークフロー自動化の全体像（2h）

**狙い：**「そもそも何を自動化するのか？」を整理し、n8nを触ってみる回。

1. オープニング＆ゴール共有（10分）

   * この講座でできるようになること
   * 「まずは一部を自動化する」というスタンスを共有

2. 業務を「フロー」で見る練習（30分）

   * 例：

     * お問い合わせ対応
     * 見込み客フォロー
     * 講座申込〜受講案内
   * 手順を「トリガー → 処理 → 出力」に分解するワーク
   * 手描き or スライドで簡易フロー図を作る

3. n8nの基本構造を理解する（30分）

   * Node（ノード）・Trigger・Flow の概念
   * 画面の見方（左：ノード一覧／中央：キャンバス／右：設定）
   * サンプル：**手動トリガー → 固定テキスト → コンソール出力**フロー

4. 最初のシンプルフローを作る（40分）

   * 例：

     * 手動トリガー → テキスト整形（Expression） → Slack or Email通知（仮想）
   * 実際には Slack ノードの設定までは見せるが、最初は「動作イメージ」を重視

5. まとめ（10分）

   * 「自分の業務で似たフローないか？」を問いかけて終了

## 第2回：SaaS連携の基本とノーコード自動化（2h）

**狙い：**既存ノードだけで「よくある業務フロー」が作れることを体験。

1. 代表的な連携先の紹介（20分）

   * Google Sheets / Slack / Gmail / Notion など
   * 「記録系」「通知系」に分けて考える

2. Google Sheets連携フロー（40分）

   * トリガー：時間ベース or 手動
   * シートから行を読み込む → 条件でフィルタ → 結果をまとめる
   * 例：**今日が期限のタスク一覧を取得**

3. Slack or メール通知フロー（40分）

   * 上で取得した「今日のタスク一覧」を整形して通知
   * メッセージのテンプレを考える
   * 例：「今日期限のタスクは○件です：…」

4. 条件分岐・分岐の考え方（15分）

   * 「条件を満たす時だけ通知」など IF ノードを実装
   * 「if で分岐した後のフロー」を視覚的に確認

5. まとめ（5分）

   * ここまでで「情報取得→整形→通知」の型ができていることを確認

## 第3回：API連携入門 – HTTPリクエストと外部サービス（2h）

**狙い：**専用ノードがなくても、HTTP RequestノードでAPIに触れる感覚を掴む。

1. REST API超入門（25分）

   * URL・メソッド（GET/POST）・ヘッダ・クエリ・ボディのざっくり説明
   * APIドキュメントの読み方「必要なところだけ」見るコツ

2. HTTP Requestノードの使い方（30分）

   * GETで外部APIからデータ取得（例：天気／為替／カレンダーなど公共系）
   * レスポンスのJSONを**n8nのUIで覗く**体験

3. APIキーと認証（30分）

   * APIキーとは何か、どこに設定するか
   * n8nの「Credentials（認証情報）」機能の使い方
   * セキュリティの注意点（平文で共有しない 等）

4. 取得データを業務フローに組み込む（25分）

   * 例：

     * 営業リストに対して、外部APIから補足情報を付与
     * ChatGPT APIで要約 → Slack通知
   * HTTP→他ノードへの値の引き継ぎを体験

5. まとめ（10分）

   * 「APIドキュメント＋HTTP Requestノードがあれば何とでもなる」イメージを作る

## 第4回：自社業務ワークフロー設計と運用のコツ（2h）

**狙い：**自社業務を題材に「実際に回せそうなワークフロー案」を作る。

1. 自社業務の棚卸しと優先度付け（30分）

   * 「毎日／毎週やっている反復作業」を書き出す
   * 「人間がやる必要がない」部分を探す

2. 自動化候補ワークフローの設計（40分）

   * 1〜2本選び、

     * トリガー
     * 中間処理
     * 通知 or 記録
   * を明文化
   * n8n上で仮フローとしてノードを並べてみる

3. 運用・エラー対応の考え方（30分）

   * ログの見方（Execution History）
   * エラー時の通知（失敗時だけSlack）
   * フローを止める／一時停止するタイミング

4. 「簡易ドキュメント」を作る（15分）

   * フローチャート + n8n URL + 説明テキスト など
   * 他のメンバーに説明できる最小限の資料

5. クロージング（5分）

   * 「1本でいいから、本当に運用してみる」を宿題にして終了
